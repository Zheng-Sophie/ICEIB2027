# AI_Conversation — AI 協作紀錄目錄

本資料夾用於保存 `ICEIB2027` 研究專案開發與論文撰寫過程中的 AI 協作紀錄，方便追蹤決策脈絡、自動化操作流程、提示詞（Prompt）與待辦事項。

## 資料夾用途

- 記錄與 Antigravity 及各類子代理（如 `browser`、`research`）或 MCP 工具協作的實作過程。
- 留存可重現的指令與 Prompt 範本，避免重複摸索環境設定或操作步驟。
- 明確區分「已驗證完成」與「待確認／尚未同步」的項目，確保論文檔案與版本控制一致性。

## 建議檔名格式

```text
YYYY-MM-DD_<主題名稱>.md
```

範例：`2026-11-25_Overleaf_Browser_Automation.md`

## 紀錄內容標準格式

每份紀錄建議包含以下 7 個章節：

1. **工作目標**：本次協作欲達成的具體目標與操作邊界限制。
2. **使用工具及環境**：涉及的作業系統、瀏覽器、遠端服務、代理／子代理、MCP 伺服器或 CLI 工具。
3. **執行步驟**：依實際執行順序列出操作流程。
4. **使用過的 Prompt**：完整保留實際下達給 AI 的關鍵提示詞（如實記錄，不事後潤飾改寫原意）。
5. **執行結果**：僅記錄工具或畫面實際回報與觀察到的輸出，未確認的修改須標示為「待確認」。
6. **遇到的問題及解決方式**：實作過程中遇到的障礙、錯誤或需釐清處，以及實際採用的處理方式。
7. **尚未完成的工作**：後續仍需處理、同步或人工覆核的事項清單。
